# titanite

titanite は Google Forms のアンケート回答を処理・匿名化・集計するための
プラグイン型フレームワークです。ICRC2023 ダイバーシティセッションの調査を
最初のプラグインとしています。

## できること

- **前処理** — 生の CSV をカテゴリ変換・地理分割・クラスタリング・ビニング
  （`SurveySchema` に沿ってプラグインが定義）
- **匿名化** — 自由記述の除去、タイムスタンプの粒度削減、k-匿名化で
  公開可能な個票抽出（`ti anonymize`）
- **集計** — n<5 セルを秘匿した頻度表とクロス集計、カイ二乗検定
  （`ti aggregate` / `ti chi2`）
- **可視化** — Altair によるヒストグラム・クロス集計・散布図

個票と自由記述はリポジトリにコミットされません。`data/public/` の
匿名化・集計済みデータのみが公開されます。
