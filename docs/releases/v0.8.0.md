# v0.8.0 - Anonymization Pipeline & Docs Split (2026-08-30)

## What Changed?

This release completes the **publish-safe data pipeline**: individual-level
survey data now stays in `data/private/` (git-ignored), and only the output
of `ti anonymize` / `ti aggregate` is committed to `data/public/`. The
analysis notebooks were rebuilt as a Quarto site that reads only those
public aggregates, Sphinx was retired in favour of Zensical (framework
docs) + Quarto (survey results), and the GitHub Actions workflows were
consolidated with the Pages deploy gated on CI success.

---

## What's New

### Main Feature: the anonymization pipeline

**What it does**:

`ti prepare` writes individual-level data to `data/private/`. Two new
commands turn that into something safe to commit:

- **`ti anonymize`** builds `data/public/public_data.csv` — a
  publication-safe individual-level extract. It drops the free-text
  columns, floors `timestamp` to the day, drops geography finer than the
  schema's quasi-identifiers plus raw numerics (`q10`, `q13`), masks rare
  values in the kept binned columns to `(rare)`, and enforces k-anonymity
  (`--k`, default 5) on `quasi_identifiers`.
- **`ti aggregate`** builds suppressed frequency tables under
  `data/public/aggregates/` — univariate counts and `--pair X,Y`
  cross-tabs, every cell with n < 5 suppressed.

**How to use it**:

```bash
cd sandbox
uv run ti prepare ../data/downloaded/survey.csv --plugin plugins.icrc2023.ICRC2023Schema
uv run ti anonymize --plugin plugins.icrc2023.ICRC2023Schema
uv run ti aggregate --plugin plugins.icrc2023.ICRC2023Schema --pair q01,q02
```

`scripts/build_public_data.sh` runs the whole sequence for the ICRC2023
survey. See [k-anonymity](../statistics/k_anonymity.md) for the privacy
model.

### Survey-results site (Quarto)

The `reports/` directory is a Quarto site covering the pre-survey
responses (Q01-Q22), the response timeline, clusters, and chi-square
results. Every page reads `data/public/` only; free-text pages show a
response count and a sentiment histogram, never verbatim answers.

### Docs split by audience

- **`docs/`** — the titanite framework docs, now built with **Zensical**
  (Material for MkDocs family) with `mkdocstrings-python` for API pages.
- **`reports/`** — the ICRC2023 survey-results site, built with Quarto.
- Both deploy to `https://www.icrc2023.org/surveys/` (Quarto at the root,
  Zensical under `/titanite/`). Sphinx is gone.

## What's Different from v0.7.0?

### ✅ Added

- **`ti anonymize`** — publication-safe individual-level dataset (#215, #228)
- **`ti aggregate`** — suppressed frequency tables (#223)
- **`data/private/` / `data/public/` boundary** — `ti prepare` and the
  analysis commands write to `data/private/`; only `data/public/` is
  committed (#220)
- **Quarto survey-results site** in `reports/` (#219, #225, #226, #229)
- **`check_sensitive_data.py` guard** — CI rejects any commit that adds a
  tracked data file with a free-text column (#222)
- **k-anonymity documentation** (#239) and `docs:release` task + template

### 🔧 Changed

- **Docs**: Sphinx retired; `docs/` → Zensical, `reports/` → Quarto,
  deployed to one Pages site by subpath (#230, #232)
- **CI**: workflows consolidated into `ci.yml`; Pages deploy runs only
  after CI passes; `update_changelog` opens a PR instead of pushing to
  `main` (#231, #235)
- **Packaging**: migrated from Poetry to uv; `poetry run` → `uv run`
  throughout the docs (#237, #238)
- `docs/titanite/*` moved up to `docs/*`; `_static/` → `assets/`

### 🐛 Fixed / Removed

- **Removed the broken `_ja` translation step** — `TextBlob.translate()`
  no longer exists; the feature is dropped and may be re-added later (#224)
- **Removed the leaked individual-level CSVs** from git history and tags
  via `git filter-repo`; they were never in a release but were reachable
  from history (#221)
- `refactor`: `_core.py` folded into `analysis.py`; unused
  `hvplot.pandas` import removed

## Is It Safe to Upgrade?

**Backward Compatible**: mostly.

- `ti prepare` and the analysis commands now default their read/write
  directory to `../data/private/` instead of `../data/main_data/`. Pass
  `--read-from` / `--write-dir` if you relied on the old default.
- The `_ja` translation columns are no longer produced. Sentiment scores
  (`*_polarity` etc.) are unaffected.
- **History rewrite**: v0.8.0 is the first tag after a `git filter-repo`.
  Existing local clones must be re-cloned; they cannot fast-forward.
